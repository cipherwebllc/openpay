# POS併用ガイド 図版 ― Codex 発注プロンプト集

`docs/guides/pos-combo-ja.md` / `/guide/pos` ページの `[[IMG: 名前]]` に対応する図版7枚。
**いずれも Codex に「インライン SVG」で作らせる前提**（軽量・ブランド配色・日本語ラベル・後から編集容易）。
生成物は `public/guide/<名前>.svg` に保存 → ページ側の図版プレースホルダを `<Image>` / `<img>` に差し替える。

## 共通スタイル（全プロンプトに含める）
- フラットイラスト/インフォグラフィック。角丸（rounded、12〜16px）。細い境界線 + ごく薄いシャドウ。
- **配色（OpenPay ブランド = Tailwind 準拠）**:
  - 店舗/プライマリ: emerald-600 `#059669` / emerald-700 `#047857` / 面 emerald-50 `#ecfdf5` / emerald-100 `#d1fae5`
  - 顧客/セカンダリ: blue-600 `#2563eb` / blue-100 `#dbeafe`
  - 文字/中立: slate-900 `#0f172a`（見出し）/ slate-600 `#475569`（本文）/ slate-200 `#e2e8f0`（罫線）/ 背景 white・slate-50 `#f8fafc`
  - 成功: emerald-500 `#10b981`
- フォント: system-ui / sans-serif。**日本語ラベルはテキスト要素で（画像化しない）**。
- レスポンシブ: `viewBox` を設定し `width="100%" height="auto"`。実在アプリのUIは模写せず抽象化。

## 1. `hero.svg`（[[IMG: hero]]）
> 次の仕様で、店頭シーンのフラットイラストを**インライン SVG**（viewBox 0 0 1200 675・16:9・width=100%/height=auto）で作って。配色は emerald-600 #059669 をプライマリ、blue-600 #2563eb をアクセント、背景 slate-50 #f8fafc。内容: カウンターにタブレットが立ち、画面に大きなQRコード（抽象的な四角ドット模様）。その手前で客が**スマホをQRにかざしている**俯瞰気味の構図。タブレット脇に小さなレジ（POS）端末。明るく親しみやすいトーン。**文字は入れない**。装飾の小さなコイン/円マーク(¥)を2〜3個だけ散らす。

## 2. `overview-flow.svg`（[[IMG: overview-flow]]）
> 横並び3ブロックのフロー図を**インライン SVG**（viewBox 0 0 1000 320）で。各ブロックは白い角丸カード（border slate-200・薄シャドウ）。左から: ①「POSレジ」見出し emerald-700 + 補足「売上を記録」slate-600 + レジのアイコン / ②「OpenPay」見出し emerald-700 + 補足「JPYCを受け取る」+ スマホ+QRアイコン / ③「閉店後に突合」見出し slate-900 + 補足「金額・番号で照合」+ チェックリストアイコン。①→②、②→③ を emerald-600 の矢印でつなぐ。日本語ラベルはテキストで。

## 3. `pos-add-method.svg`（[[IMG: pos-add-method]]）
> POSレジの「支払い方法」設定画面の**模式図**をインライン SVG（viewBox 0 0 760 480）で。白い角丸パネルに縦並びのリスト行: 「現金」「クレジットカード」「電子マネー」、そして最下行に **emerald で強調した「OpenPay」**（+バッジ「追加」）。最上部に小見出し「支払い方法」slate-900。実在アプリの模写はせず抽象UI。emerald-600/100 と slate を使用。日本語テキスト。

## 4. `four-steps.svg`（[[IMG: four-steps]]）
> 4ステップの横タイムラインをインライン SVG（viewBox 0 0 1100 280）で。丸番号①〜④（emerald-600 塗り・白文字）+ 各カードに見出し+小アイコン: ①「会計→『OpenPay』で通す」レジアイコン / ②「同じ金額でQRを表示」QRアイコン / ③「お客様がスキャンして支払い」スマホアイコン / ④「『支払い完了』を確認」緑チェック。番号間を細い矢印でつなぐ。日本語テキスト、配色は emerald 基調 + slate。

## 5. `payment-success.svg`（[[IMG: payment-success]]）
> スマホ画面の決済完了表示をインライン SVG（viewBox 0 0 420 720・縦長）で。スマホの枠（角丸・slate-900 の細枠）の中央に**大きな緑の円 + 白いチェックマーク**（emerald-500 #10b981）。その下に見出し「支払い完了」slate-900・小さく金額例「¥1,200」と通貨「JPYC」。安心感のある余白多めのレイアウト。背景 white。日本語テキスト。

## 6. `history-reconcile.svg`（[[IMG: history-reconcile]]）
> 売上突合のインフォグラフィックをインライン SVG（viewBox 0 0 1000 420）で。左カード「POS：その他決済」に明細行（時刻 / ¥金額 / 番号）を2〜3行・blue 基調。右カード「OpenPay：履歴 / CSV」に対応する着金行・emerald 基調。中央に双方向矢印 + ラベル「金額・レシート番号で一致」slate-700。下部に小さく「CSVを出力」アイコン。白カード + slate-200 罫線。日本語テキスト。

## 7. `cost-compare.svg`（[[IMG: cost-compare]]）
> コスト比較のインフォグラフィックをインライン SVG（viewBox 0 0 900 360）で。2カラム比較: 左「一般的なカード決済」slate 基調（棒グラフ高め・ラベル「数％程度」※具体数値は入れず“高め”を示すだけ）/ 右「無料POS × OpenPay」emerald 基調（棒グラフ低め・ラベル「軽いご利用料」）。下に3つの小アイコン行: 「即時・直接着金」「ノンカストディ」「初期費用ゼロ」。**具体的な料率の数字は入れない**（相対的な高低のみ。参考: カード約3% vs OpenPay 約1%）。日本語テキスト、emerald/blue/slate。
